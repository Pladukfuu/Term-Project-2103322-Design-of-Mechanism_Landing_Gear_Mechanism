# Media

โฟลเดอร์นี้รวบรวมภาพเรนเดอร์ 3 มิติ ภาพตำแหน่งการทำงานของกลไก และวิดีโอสาธิตการเคลื่อนที่ (Animation) ของกลไกพับล้อเครื่องบิน

---

## 1. Project Images (`project images/`)
ภาพแสดงรายละเอียดชิ้นส่วนและตำแหน่งการทำงานหลักของกลไก:

* **`Render.png`** – ภาพเรนเดอร์ 3 มิติ (3D Isometric Render) แสดงการประกอบชิ้นส่วนทั้ง 10 ลิงก์ของกลไกพับล้อเครื่องบิน
* **`extended_position.png`** – ภาพกลไกในตำแหน่งกางสุด (Fully Extended Position)
* **`retracted_position.png`** – ภาพกลไกในตำแหน่งพับเก็บสุด (Fully Retracted Position)
